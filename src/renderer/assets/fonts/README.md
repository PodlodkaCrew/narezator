Local brand font assets supplied with the user's Podlodka identity materials:

- `elma-mono-regular.woff2` — Elma Mono Regular, from `type.today-elma-mono-regular-web` in Downloads. Used for all interface text, including Cyrillic transcript text.
- `ease-geometric-a-black.woff2` — Ease Geometric A Black, from `Ease Geometric A+B Black/2 Web` in Downloads. Used for the Narezator wordmark and project welcome heading.

Both fonts are bundled locally by Vite, with no remote font requests. The palette and panel geometry follow pages 21, 26–33 and 47 of `podlodka × Non-Objective — Identity guides.pdf`.
